{{ .Chart.Name }} {{ .Chart.Version }} installed as release {{ .Release.Name }} in namespace {{ .Release.Namespace }}.

Wait for all eight pods:

    kubectl -n {{ .Release.Namespace }} get pods -w

Reach the platform. The gateway is the only entry point (ADR-0009); Keycloak is forwarded
too because the demo fetches a real token from it:

    kubectl -n {{ .Release.Namespace }} port-forward svc/api-gateway 8090:8090 &
    kubectl -n {{ .Release.Namespace }} port-forward svc/keycloak 8180:8080 &

Those are the same ports the compose stack publishes, so the demo runs unchanged:

    make demo

Tokens issued through the port-forward carry iss={{ include "platform.issuerUri" . }},
which is what the services inside the cluster expect. That is deliberate: the issuer is an
in-cluster address on both sides.

Follow one saga across every service by the correlationId the demo prints:

    kubectl -n {{ .Release.Namespace }} logs -l app.kubernetes.io/part-of=event-driven-order-platform \
      --tail=-1 --prefix | grep <correlationId>
